## 🌙 About DEEN

**DEEN** is an Android Islamic companion application created to help Muslims access useful Islamic resources and manage everyday worship through a single application.

The goal is to provide a simple, accessible, and user-friendly experience with support for Islamic learning, daily worship, personal notes, and customization.

DEEN aims to make everyday Islamic practices more organized and convenient.

## ✨ Features

The project includes the following feature areas. Availability depends on the current application build.

### 🕌 Worship & Daily Practice
- Prayer time information
- Qibla direction assistance
- Digital Tasbih for Dhikr counting
- Daily worship support

### 📖 Islamic Knowledge
- Quran reading resources
- Hadith collection and references
- Dua and Azkar
- Islamic learning resources

### 📝 Islamic Notebook
- Personal Islamic notes
- Save important reminders
- Organize personal learning notes
- Keep useful Islamic information together

### 🌍 Personalization
- Bengali and English language support
- Arabic-friendly reading experience
- Font and reading preferences
- App theme customization
- Location and timezone preferences, where supported

### ⚙️ User Experience
- Organized navigation
- Simple and clean interface
- Personalized settings
- Easy access to important features

## 🚀 Getting Started

### Requirements

- Android Studio
- Android SDK
- Compatible JDK
- Internet connection for Gradle dependency downloads

### Clone the Repository

```bash
git clone https://github.com/huzzatulislamtaha/Deen-2.0.git
```

Open the project in Android Studio and wait for Gradle Sync to finish.

### Build the Application

**Windows:**

```powershell
.\gradlew.bat assembleDebug
```

**Linux / macOS:**

```bash
./gradlew assembleDebug
```

The generated debug APK is usually located at:

```text
app/build/outputs/apk/debug/
```

## 🕌 Islamic Content & Authenticity

Islamic content requires accuracy and responsible verification.

DEEN aims to maintain the integrity of Islamic resources by following these principles:

- Preserve Arabic text accurately.
- Provide reliable source references.
- Verify Hadith wording and authenticity grades.
- Use trustworthy translations.
- Avoid fabricated religious references.
- Clearly identify content that has not yet been verified.

The application is an informational companion and does not replace qualified Islamic scholars.

## 🔐 Privacy & Security

User privacy and application security are important.

- Protect API keys and sensitive credentials.
- Never commit secrets to a public repository.
- Request only necessary Android permissions.
- Handle location and personal data responsibly.
- Keep local configuration files secure.
